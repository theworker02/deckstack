# deckstack

Deck structured JSON stack payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/deckstack/

## Install / run

```bash
git clone https://github.com/theworker02/deckstack.git
cd deckstack
node src/cli.js
node --test
```
